1.	Jelaskan apa itu Bootstrap dan apa kegunaannya!
Bootstrap adalah framework CSS open-source yang digunakan untuk mempermudah dan mempercepat proses pembuatan tampilan website. Bootstrap menyediakan berbagai komponen siap pakai, seperti tombol, navigasi, formulir, tabel, kartu, dan sistem grid sehingga pengembang tidak perlu membuat semua desain dari awal.

3.	Jelaskan mengenai class grid dan kegunaan breakpoint!
Grid adalah sistem tata letak Bootstrap yang digunakan untuk menyusun elemen website ke dalam baris (row) dan kolom (column). Sistem grid Bootstrap menggunakan 12 kolom sebagai dasar pembagian lebar halaman, sehingga tata letak dapat dibuat lebih fleksibel dan responsif.
Breakpoint adalah batas ukuran lebar layar yang digunakan Bootstrap untuk menyesuaikan tampilan website berdasarkan perangkat yang digunakan. Breakpoint membantu website menampilkan tata letak yang sesuai pada ponsel, tablet, laptop, dan layar yang lebih besar.

5.	Text-center : Membuat teks rata tengah.

5. Bagaimana cara agar foto atau gambar pada website responsif menyesuaikan ukuran layar perangkat?
Agar gambar pada website responsif dan dapat menyesuaikan ukuran layar perangkat, Bootstrap menyediakan class img-fluid. Class ini membuat gambar memiliki lebar maksimum 100% dari wadahnya dan tinggi otomatis mengikuti proporsi gambar.
